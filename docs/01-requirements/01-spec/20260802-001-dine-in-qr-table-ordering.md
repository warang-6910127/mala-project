# ระบบสั่งกาแฟที่โต๊ะด้วย QR Code

> สร้างเมื่อ: 2026-08-02 | สถานะ: Backlog

## บริบท / ที่มา (Background)

- ปัจจุบันลูกค้าต้องเดินไปสั่งและจ่ายเงินที่เคาน์เตอร์ก่อนถึงจะได้นั่งโต๊ะ
- ต้องการให้ลูกค้าที่นั่งโต๊ะแล้วสามารถสั่งกาแฟ/เมนูได้เองจากที่โต๊ะ โดยไม่ต้องลุกไปเข้าคิว

## ขอบเขต (Scope)

### สิ่งที่ต้องทำ (In scope)

- ลูกค้าสแกน QR code ที่ติดอยู่บนโต๊ะ เพื่อเปิดหน้าสั่งอาหารผ่านเว็บ/มือถือของลูกค้าเอง (ไม่ต้องติดตั้งแอป)
- ลูกค้าเลือกเมนู ยืนยันออเดอร์ และชำระเงินทันทีในขั้นตอนเดียวกัน (เช่นผ่าน QR พร้อมเพย์) ก่อนออเดอร์จะถูกส่งเข้าครัว
- ออเดอร์ที่ชำระเงินสำเร็จแล้วต้องขึ้นแสดงบนจอหลังร้านแบบเรียลไทม์ (Kitchen Display System / KDS) ให้บาริสต้าเห็นทันที
- แต่ละ QR code ต้องระบุหมายเลข/ชื่อโต๊ะ เพื่อให้บาริสต้ารู้ว่าออเดอร์นี้เป็นของโต๊ะไหน

### สิ่งที่ไม่ทำ (Out of scope)

- การสั่งล่วงหน้า/สั่งกลับบ้าน (pre-order, delivery, takeaway) — เป็นคนละ flow กับการสั่งที่โต๊ะ
- การจ่ายเงินแบบเก็บเงินสดหรือรวมบิลท้ายสุด — เพราะเลือกให้จ่ายก่อนออเดอร์เข้าครัวแล้ว
- การแจ้งเตือนครัวผ่านใบพิมพ์ (printer ticket) หรือ LINE — ตกลงใช้ KDS เป็นช่องทางเดียว

## User Story / Use Case

- ในฐานะลูกค้าที่นั่งโต๊ะอยู่ ฉันต้องการสแกน QR code ที่โต๊ะแล้วสั่งกาแฟได้เอง เพื่อไม่ต้องลุกไปต่อคิวที่เคาน์เตอร์
- ในฐานะบาริสต้า ฉันต้องการเห็นออเดอร์ที่จ่ายเงินแล้วขึ้นจอทันที พร้อมหมายเลขโต๊ะ เพื่อทำเครื่องดื่มและเสิร์ฟถูกโต๊ะ

## กฎทางธุรกิจ (Business Rules)

- **วิธีสั่ง**: ลูกค้าต้องสแกน QR code เฉพาะของโต๊ะนั้นๆ เพื่อเข้าสู่หน้าสั่งอาหาร ไม่มีช่องทางสั่งอื่นในเวอร์ชันนี้
- **การชำระเงิน**: ระบบต้องยืนยันว่าชำระเงินสำเร็จ (เช่น QR พร้อมเพย์) ก่อนจึงจะส่งออเดอร์เข้าคิวของ KDS ได้ — ออเดอร์ที่ยังไม่จ่ายเงินต้องไม่ปรากฏบนจอครัว
- **การแจ้งครัว**: ออเดอร์ที่จ่ายเงินสำเร็จต้องปรากฏบนจอ KDS แบบเรียลไทม์ พร้อมหมายเลขโต๊ะและรายการที่สั่ง

## เกณฑ์การยอมรับ (Acceptance Criteria)

- [ ] ลูกค้าสแกน QR code ที่โต๊ะแล้วเข้าสู่หน้าสั่งอาหารที่ระบุหมายเลขโต๊ะถูกต้อง
- [ ] ลูกค้าสั่งเมนูและชำระเงินสำเร็จได้ในขั้นตอนต่อเนื่องเดียวกัน
- [ ] ออเดอร์จะไม่ถูกส่งเข้า KDS จนกว่าการชำระเงินจะสำเร็จ
- [ ] ออเดอร์ที่ชำระเงินสำเร็จปรากฏบนจอ KDS แบบเรียลไทม์ พร้อมหมายเลขโต๊ะและรายการอาหาร
