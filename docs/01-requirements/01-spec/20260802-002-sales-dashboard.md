# Dashboard ดูยอดขาย

> สร้างเมื่อ: 2026-08-02 | สถานะ: Backlog

## บริบท / ที่มา (Background)

- เจ้าของร้าน/ผู้จัดการต้องการเห็นภาพรวมยอดขายของร้าน เพื่อใช้ตัดสินใจทางธุรกิจ (เช่น ปรับเมนู, ดูแนวโน้มยอดขาย)
- ปัจจุบันยังไม่มีช่องทางดูยอดขายสรุปแบบรวมศูนย์

## ขอบเขต (Scope)

### สิ่งที่ต้องทำ (In scope)

- แสดงยอดขายรวม แยกตามช่วงเวลา: รายวัน / รายสัปดาห์ / รายเดือน (เลือกช่วงแบบมาตรฐาน ไม่ใช่ custom date range อิสระ)
- แสดงยอดขายแยกตามเมนู เพื่อดูว่าเมนูไหนขายดี/ขายน้อย ในช่วงเวลาที่เลือก
- จำกัดการเข้าถึง dashboard ให้เฉพาะเจ้าของร้าน/ผู้จัดการเท่านั้น

### สิ่งที่ไม่ทำ (Out of scope)

- การเลือกช่วงวันที่แบบอิสระ (custom date range) — เก็บไว้พิจารณาในเวอร์ชันถัดไป
- การเปิดให้พนักงานทั่วไปเข้าถึงข้อมูลยอดขาย
- การวิเคราะห์เชิงลึก เช่น พยากรณ์ยอดขาย (forecasting) หรือเปรียบเทียบข้ามสาขา (ร้านนี้มีสาขาเดียว)

## User Story / Use Case

- ในฐานะเจ้าของร้าน ฉันต้องการดูยอดขายรวมรายวัน/สัปดาห์/เดือน เพื่อติดตามผลประกอบการของร้าน
- ในฐานะเจ้าของร้าน ฉันต้องการดูยอดขายแยกตามเมนู เพื่อรู้ว่าเมนูไหนขายดีและควรโปรโมทหรือปรับปรุงเมนูไหน

## กฎทางธุรกิจ (Business Rules)

- **สิทธิ์การเข้าถึง**: เฉพาะบัญชีเจ้าของร้าน/ผู้จัดการเท่านั้นที่เห็น dashboard นี้ได้ ไม่เปิดให้พนักงานทั่วไป
- **ช่วงเวลาที่ดูได้**: เลือกได้เฉพาะ รายวัน / รายสัปดาห์ / รายเดือน เท่านั้นในเวอร์ชันนี้
- **มุมมองข้อมูล**: ต้องมีอย่างน้อย 2 มุมมอง คือ (1) ยอดขายรวมตามช่วงเวลา และ (2) ยอดขายแยกตามเมนู

## เกณฑ์การยอมรับ (Acceptance Criteria)

- [ ] ผู้ใช้ที่เป็นเจ้าของร้าน/ผู้จัดการเข้าถึง dashboard ได้ ส่วนบัญชีอื่นเข้าไม่ได้
- [ ] เลือกดูยอดขายรวมแบบรายวัน รายสัปดาห์ และรายเดือนได้ครบทั้ง 3 แบบ
- [ ] ดูยอดขายแยกตามเมนูในช่วงเวลาที่เลือกได้
- [ ] ตัวเลขยอดขายที่แสดงตรงกับออเดอร์ที่ชำระเงินสำเร็จจริง
