# 01 - Prototypes

เก็บ **ต้นแบบหน้าตาของระบบ (UI/UX Prototype)** เช่น

- Wireframe / mockup ของแต่ละหน้าจอ — ดู [[prototypes/index|prototypes]] (รายการเวอร์ชัน v1, v2, ... แต่ละเวอร์ชันเป็น Markdown wireframe แบบ text-based)
- User flow และ navigation flow — ดู [[user-journey|user-journey]] (Mermaid diagram แยกตาม persona พร้อม mapping กลับไปหา requirement)
- Design system เบื้องต้น เช่น สี ฟอนต์ คอมโพเนนต์หลัก — ดู [[DESIGN|DESIGN.md]] (Brand identity, design tokens, UI components, UX guidelines)

ใช้สำหรับสื่อสารและตกลงหน้าตาของระบบก่อนลงมือพัฒนาจริง โดยอ้างอิงความต้องการจาก [[../../01-requirements/01-spec/index|01-spec]] และส่งต่อรายละเอียดเชิงระบบให้ [[../02-technical/index|02-technical]]
